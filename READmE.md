# 🌍 Smart Tourist Safety Monitoring System

## 🚀 Overview
This project is a real-time tourist safety system using:
- AI-based risk detection
- Geo-fencing
- Blockchain-based digital ID (simulated)

## 🔐 Features
- User authentication
- Emergency alert system
- Geo-fencing alerts
- Live dashboard with map
- AI risk classification

## ⚙️ Technologies Used
- Node.js
- Express.js
- JavaScript
- Leaflet.js (maps)

## ▶️ How to Run

```bash
npm install
node server.js
